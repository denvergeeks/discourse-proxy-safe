# **Discourse Proxy Safe**

This is a helper plugin for the https://github.com/denvergeeks/discourse-rich-previews Theme Component (where Internal Topics and Wikipedia Links work out of the box). However, the Remote Topics feature (getting previews of Topics from other Discourse sites), requires adding this plugin to your app.yml
https://github.com/denvergeeks/discourse-proxy-safe.git
